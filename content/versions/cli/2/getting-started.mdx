## The native executable

The CLI creates and validates workspace records, manages repository bindings, prepares worktrees, derives dependencies, and emits dispatch specifications. The agent still owns judgment and implementation; the person owns authorization.

## Install and use

Follow [CLI installation](/docs/cli/installation), resolve the [workspace version pin](/docs/cli/version-pinning), then read the [command reference](/docs/reference/cli-commands). The shared executable on PATH may point at a different workspace's version.

## Version baseline

This major guide is verified against CLI 2.1.0, which adds configurable GitHub and GitLab installer registries. Read [2.1.0 release notes](/releases/cli/2.1.0) and the independent [CLI changelog](/changelog/cli).

The native CLI began at 2.0.0. There is no CLI 1.x history, and initialization does not migrate a v1 workspace.
