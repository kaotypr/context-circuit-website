The workspace template stores project identity, intent, plans, and durable
knowledge in reviewable files.

Create a workspace from the tagged release, then ask the agent to initialize it
for your project and connect the repositories it coordinates. The workspace's
root instructions keep authorization boundaries active in every session, while
stage-specific skills load only when their procedure is needed.

## Release line

This guide is pinned to template release 2.1.0. See its
[release page](/releases/template/2.1.0).
