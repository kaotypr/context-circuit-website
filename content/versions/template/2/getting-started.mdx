## What v2 provides

The workspace preserves product knowledge, intended outcomes, plans, and human decisions in ordinary Markdown and YAML. Root instructions keep authorization boundaries active; skills carry stage-specific procedures. The native CLI provides deterministic mechanics.

## Start using it

Follow [install the template](/docs/get-started/install), [initialize a workspace](/docs/get-started/initialize), and [connect repositories](/docs/get-started/connect-repositories). Then take one change through the [first workflow](/docs/get-started/first-workflow).

## Version baseline

This major guide is verified against template 2.1.0, which adds the optional CLI registry setting. For the exact change, read [2.1.0 release notes](/releases/template/2.1.0). The [template changelog](/changelog/template) preserves 2.0.0 and 2.1.0 separately.

No v1 guide is available here. Applying a template upgrade uses the tag delta and preserves the project's own files.
