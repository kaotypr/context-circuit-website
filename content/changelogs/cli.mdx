## 2.3.0 — solo workspaces and record deletion

Initialization can create a solo workspace without a member. Team workspaces report when this machine needs a member selection. Record deletion previews the affected records, requires confirmation, and releases their IDs for reuse.

[Read CLI 2.3.0](/releases/cli/2.3.0)

## 2.2.0 — plan folders and exact runs

New plans use a folder with `plan.md` and optional assigned details. Plans may be standalone, and `record order --plan ID` selects an exact run. Legacy plans remain readable.

[Read CLI 2.2.0](/releases/cli/2.2.0)

## 2.1.0 — registry-aware installers

Installers accept GitHub or GitLab registry settings through flags or environment variables. GitLab requires a token. Checksum and embedded-version verification remain in place.

[Read CLI 2.1.0](/releases/cli/2.1.0)

## 2.0.0 — first native executable

The first native CLI provides workspace records, bindings, worktrees, ordering, diagnostics, and dispatch specifications. It begins at 2.0.0 alongside the template; no native CLI 1.x exists.

[Read CLI 2.0.0](/releases/cli/2.0.0)

## Coverage

This timeline includes verified stable releases 2.0.0 through 2.3.0. No patch entries are inferred. The [major-version policy](/docs/releases/major-versions) distinguishes guides from release notes and identifies unavailable historical documentation.
