## 2.1.0 — registry-aware installers

Installers accept GitHub or GitLab registry settings through flags or environment variables. GitLab requires a token. Checksum and embedded-version verification remain in place.

[Read CLI 2.1.0](/releases/cli/2.1.0)

## 2.0.0 — first native executable

The first native CLI provides workspace records, bindings, worktrees, ordering, diagnostics, and dispatch specifications. It begins at 2.0.0 alongside the template; no native CLI 1.x exists.

[Read CLI 2.0.0](/releases/cli/2.0.0)
