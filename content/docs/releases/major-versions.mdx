## Minor and patch changes

The [template changelog](/changelog/template) and [CLI changelog](/changelog/cli) are independent timelines. Exact release pages preserve the changes for 2.0.0 and 2.1.0. A future patch belongs to its own product's timeline; the website does not invent entries for unreleased versions.

## Historical availability

No v1 documentation collection is published here. The available v2 release notes describe the retirement of v1 machinery, but they are not a reconstructed v1 manual. The native CLI is new in v2 and has no 1.x release line.

The major v2 guides identify 2.1.0 as their evidence baseline. Selecting 2.0.0 opens its release notes, not a falsely relabeled 2.1.0 guide.
