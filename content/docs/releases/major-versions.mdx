## Minor and patch changes

The [template changelog](/changelog/template) and [CLI changelog](/changelog/cli) are independent timelines. Exact release pages preserve the changes from 2.0.0 through 2.5.0, stable releases only. A release candidate, such as 2.5.0-rc.1, is a prerelease of the stable line and has no notes of its own: the stable release that follows it covers everything since the previous stable release. A future patch belongs to its own product's timeline; the website does not invent entries for unreleased versions.

## Release lines

A stable version, `X.Y.Z`, is on the stable release line. A variant version, `X.Y.Z-<label>.N`, is on that label's own line, published by a fork. A workspace's pin updates only along its own line: a stable pin among stable releases, and a `<label>` pin among that label's releases. Moving to another line is a template change a person names by its exact tag, and a CLI from another line refuses changes to the workspace.

## Historical availability

No v1 documentation collection is published here. The available v2 release notes describe the retirement of v1 machinery, but they are not a reconstructed v1 manual. The native CLI is new in v2 and has no 1.x release line.

The major v2 guides identify 2.5.0 as their evidence baseline. Selecting an earlier release opens its release notes, not a falsely relabeled current guide.
