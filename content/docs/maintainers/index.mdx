The source repository builds two products but publishes them independently.
Public documentation should explain tagged behavior in reader-oriented prose,
not import the maintainer checkout during a website build.

## Maintain a release

Read the [release boundaries](/docs/maintainers/releases), then update the
matching track's changelog and release page with immutable source metadata.
