The workspace template is published from `context-circuit` under 0BSD with
`v*` tags. The native CLI is built from `context-circuit-source` under
Apache-2.0 with `cli-v*` tags.

## Documentation rule

Major releases receive selectable versioned collections. Minor and patch
releases stay in the matching track changelog and receive a release page only
when the change needs more explanation. Every source link uses the exact tag
and repository for its track.
