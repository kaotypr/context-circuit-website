Context Circuit separates human decisions about outcomes from implementation
details. Start by creating the workspace, then let its bundled `cc-cli` skill
install the pinned native CLI for your platform.

## Choose a track

- [Install Context Circuit](/docs/get-started/install) for a fresh project.
- Read the [workspace template guide](/docs/template/v2/getting-started).
- Read the [CLI guide](/docs/cli/v2/getting-started).
- Follow the [project workflow](/docs/workflows).
