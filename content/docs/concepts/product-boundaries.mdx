The workspace stores shared knowledge, intents, plans, member records, and
repository relationships. The CLI performs operations that must return the same
result every time. The coding agent reads the actual project and exercises
judgment. A person supplies consent for approval, execution, delivery, and
completion.

## Independent release tracks

The workspace template uses `v*` tags in `context-circuit`. The native CLI uses
`cli-v*` tags in `context-circuit-source`. A workspace pins its expected CLI in
`.context-circuit/CLI_VERSION`; matching version numbers do not combine the two
products.
