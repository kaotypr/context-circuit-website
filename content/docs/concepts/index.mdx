Context Circuit keeps project understanding close to the work while making the
consequential decisions visible to a person.

## Core ideas

- A [workspace](/docs/concepts/product-boundaries) coordinates repositories but
  does not replace them.
- An intent settles an outcome before detailed implementation planning.
- Plans record intended work; code and commits record what actually happened.
- Durable knowledge is reconciled only when a person marks work complete.
