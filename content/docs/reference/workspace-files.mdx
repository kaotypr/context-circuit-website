`workspace.yaml`, `members.yaml`, `context/`, `intent/`, and `plans/` are shared
through Git. `member.local.yaml`, `repositories.local.yaml`, local locks, and
worktree associations stay ignored because they describe one machine.

## Repository identity

`workspace.yaml` gives every logical repository a stable ID, URL, default
branch, and relationship to its peers. The local bindings map those IDs to
checkout paths and machine-specific base branches without publishing paths from
one computer into another's workspace.
