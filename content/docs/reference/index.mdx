Use these pages when you need the exact shape of a file or command, not an explanation of why it exists. Schema, record fields, relationship entries, version tags, configuration files, and CLI signatures are verified against template 2.1.0 and CLI 2.1.0.

Workspace identity uses schema version 2. Intent and plan records use canonical ISO 8601 UTC timestamps for instants and calendar dates everywhere else. IDs are workspace-global and are never reused.

If you are looking for the product model rather than a field list, start at [Understand](/docs/understand).
