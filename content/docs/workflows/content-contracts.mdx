## One content graph

MDX frontmatter supplies title, description, section, order, audience, product scope, independent version selections, and pinned sources. That graph drives routes, navigation, search, and source metadata. Draft and unlisted content is excluded from publication.

## Stable paths and source evidence

Major guides use `/docs/template/v2/` and `/docs/cli/v2/`. Release notes use exact versions under `/releases/`; the two changelogs stay separate. Internal links, fragments, source paths, and release selections are checked before export.

New website files have no published revision until committed. Their footer names the local MDX path instead of inventing a remote link. Existing files link to a verified website snapshot; this is not a claim that uncommitted edits are published.

See [documentation contribution](/docs/maintainers/documentation).
