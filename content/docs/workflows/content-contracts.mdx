## The content tree is the site

Every MDX file under `content/` is a page, and its path is its URL. Frontmatter supplies the title, description, product tracks, independent version selections, and optional pinned sources; unknown fields fail the build. Folder `meta.json` files order the sidebar and name its sections. The same source drives routes, navigation, and the static search index.

## Stable paths and source evidence

Major guides use `/docs/template/v2/` and `/docs/cli/v2/`. Release notes use exact versions under `/releases/`; the two changelogs stay separate. Every release in the registry has a note and a changelog entry, newest first, and the static check confirms each one was exported.

Source links name a repository, an immutable tag, and a path. They are written when the claim is checked and render as plain links in the page footer.

See [documentation contribution](/docs/maintainers/documentation).
