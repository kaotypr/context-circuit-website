The workflow makes human decisions visible while leaving implementation details
to the repository that owns them.

## Lifecycle

Begin with an intent, plan after approval, execute only when requested, and
reconcile durable knowledge when the work is explicitly completed. Read the
[change lifecycle](/docs/workflows/change-lifecycle) for each control point.
