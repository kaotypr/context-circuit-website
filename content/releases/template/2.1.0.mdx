Template 2.1.0 adds the optional `cli_registry` workspace setting. Its `source`,
`repository`, and `api` fields let the bundled installation skill obtain the
CLI from an explicitly selected GitHub or GitLab registry. A workspace without
the setting behaves exactly as it did in 2.0.0.
