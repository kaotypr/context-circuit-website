## The v2 workspace

The release replaces the older lifecycle machinery with a native CLI boundary, explicit outcome approval and execution decisions, durable product knowledge, and isolated worktrees. Context and repository relationships ground the next intent; completion reconciles changed knowledge.

The source release notes also describe borrowed knowledge, system-design source material, dependency ordering, native role dispatch, and record language support.

## Compatibility and history

Records from 2.0.0-rc.4 and later remain readable. This is not a v1 migration guide. The [template changelog](/changelog/template) links the independently released 2.1.0 addition.
