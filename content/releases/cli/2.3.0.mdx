CLI 2.3.0 allows `init` without `--member`. This creates a solo workspace with
an empty roster, no selected member, and records without `created_by`. Adding
members later turns it into a team workspace without invalidating those records.

In a team workspace, `status` reports `identity_required` when this machine has
no selected member or selects one absent from the roster. `record create`
explains how to select a member before writing.

`record delete --member ID` previews the intents and plans created by one member
in a team workspace. `record delete --all` previews all records in a solo
workspace. Both include archived records and release their IDs for reuse. The
command deletes nothing without `--confirm`, and refuses deletion when another
member's record or a local plan worktree would be left referring to the records.
