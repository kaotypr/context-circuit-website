## First native CLI

The Go executable supplies stable record IDs, structured file edits, repository bindings, worktrees, dependency ordering, diagnostics, and dispatch specifications. It carries no model credentials and makes no product judgments.

The CLI starts at 2.0.0 because it was introduced alongside workspace v2. No native 1.x or 0.x release preceded it.

## Installation and compatibility

Native archives cover macOS, Linux, and Windows on amd64 and arm64. Versions coexist in a local store. Records from 2.0.0-rc.4 and later remain readable; initialization does not migrate v1.

See the [CLI changelog](/changelog/cli) for the separately released registry support in 2.1.0.
