<p className="hero-note">A calmer circuit from request to durable project knowledge.</p>

Context Circuit gives coding agents shared project context, a grounded plan, and
explicit human control points across one or more repositories. The workspace
keeps the decisions readable; the native CLI handles deterministic bookkeeping.

## Start with the workflow

Read [Getting started](/docs/get-started), explore the [documentation](/docs), choose the
[workspace template](/docs/template/v2/getting-started), or learn the
[CLI](/docs/cli/v2/getting-started).

<InstallLink href="/docs/get-started/install" destination="template">Install the workspace template</InstallLink>

## Two products, independent releases

The workspace template and CLI can share a version number without sharing a
release identity. Every versioned page here names its track and links to the
matching immutable source.
